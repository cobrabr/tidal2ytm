# Logging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** File-based diagnostic logging via stdlib `logging` so matching, auth, and transfer misbehaviour can be diagnosed from one timestamped log file without reproducing a run.

**Architecture:** One new owner module (`logging_setup.py`) holds level vocabulary, precedence resolution, per-run file-handler setup, and a `log_call` adapter that stamps duration and classifies failures. `cli.main()` initializes logging once before dispatch; external-facing modules gain module loggers and emit per the spec's level table. Console output is never used for log records.

**Tech Stack:** Python stdlib `logging` only; no new dependency.

**Spec:** docs/superpowers/specs/2026-09-24-logging-design.md

## Global Constraints

- Every module begins with `from __future__ import annotations`; public functions are type-annotated.
- CLI level names are exactly `OFF, CRITICAL, ERROR, WARN, INFO, DEBUG` (case-insensitive), one-to-one onto stdlib levels; no `TRACE`.
- Formatter is exactly `%(asctime)s %(levelname)-5s %(name)s %(message)s`.
- Per-run file: `logs/YYYYMMDD-HHMMSS-ffffff.log` (microseconds, timezone-aware `datetime`); one file per process; repeated `setup_logging` calls in one process reuse the same file.
- `OFF` attaches no handler, creates no file, creates no directory.
- `logs/` is a sibling of `data/` (`Path("logs")`), created lazily at setup — never on import. `.gitignore` gains `logs/`.
- Default level `INFO`. Precedence: flag > `TIDAL2YTM_LOG_LEVEL` env > default. Invalid env value is a hard CLI error (never a silent fallback to INFO).
- Log records never contain tokens, client secrets, or authorization headers. Payload logging at `DEBUG` redacts token-bearing fields via the redaction helper.
- `log_call`'s broad `except Exception` arm always re-raises — it is an observer that logs and re-raises, never a suppressor. Connection-level failures (`requests.ConnectionError`) log at `CRITICAL`, other failures at `ERROR`.
- No console output for log records; console behaviour is unchanged in every task.
- Paths live in `paths.py` (one owner); `LOG_LEVELS` lives in `logging_setup.py` (one owner).
- Records at every level go to the file only; third-party loggers (`requests`, `urllib3`, `ytmusicapi`) propagate to the root handler unchanged.
- Tests assert structural membership (level, logger name, message substrings) via `caplog`, never exact formatted lines.

## Review Focus

1. `logs/` not writable → `RuntimeError` naming the path, never a silent drop. Test in Task 1.
2. Credential leakage: a `DEBUG` record built from a token-bearing payload never contains `access_token`/`refresh_token`/`Authorization` values. Test in Task 3.
3. Third-party records (a non-`tidal2ytm` logger, e.g. `urllib3`) reach the run file from `INFO` up. Test in Task 1.
4. Two runs started within the same second produce distinct filenames (microseconds segment present). Test in Task 1.
5. Invalid `TIDAL2YTM_LOG_LEVEL` env value → hard CLI error, not silent `INFO`. Test in Task 2.

```python
from __future__ import annotations

import datetime
import logging
import time
from collections.abc import Callable
from typing import Any

import requests

from .paths import ensure_logs_dir, LOGS_DIR

# Single owner of the CLI level vocabulary; one-to-one onto stdlib levels.
LOG_LEVELS: dict[str, int] = {
    "OFF": logging.CRITICAL + 1,
    "CRITICAL": logging.CRITICAL,
    "ERROR": logging.ERROR,
    "WARN": logging.WARNING,
    "INFO": logging.INFO,
    "DEBUG": logging.DEBUG,
}

_REDACT_KEYS = frozenset({"access_token", "refresh_token", "authorization", "client_secret"})

_HANDLER: logging.Handler | None = None
_RUN_FILE = None  # Path | None, set at first non-OFF setup


def resolve_level(flag_value: str | None, env_value: str | None) -> str:
    """flag > env > default INFO; raises ValueError on an unknown name."""
    raw = flag_value or env_value or "INFO"
    name = raw.strip().upper()
    if name not in LOG_LEVELS:
        raise ValueError(f"Unknown log level: {raw!r}")
    return name


def _run_file() -> Path:
    global _RUN_FILE
    if _RUN_FILE is None:
        stamp = datetime.datetime.now(datetime.UTC).astimezone().strftime("%Y%m%d-%H%M%S-%f")
        _RUN_FILE = ensure_logs_dir() / f"{stamp}.log"
    return _RUN_FILE


def setup_logging(level_name: str) -> Path | None:
    """Attach the per-run file handler at the resolved level; None for OFF."""
    global _HANDLER
    name = resolve_level(level_name, None)
    if name == "OFF":
        return None
    level = LOG_LEVELS[name]
    try:
        path = _run_file()
    except OSError as exc:
        raise RuntimeError(f"Log directory not writable: {LOGS_DIR}") from exc
    root = logging.getLogger()
    if _HANDLER is None:
        handler = logging.FileHandler(path, encoding="utf-8")
        handler.setFormatter(
            logging.Formatter("%(asctime)s %(levelname)-5s %(name)s %(message)s")
        )
        handler._tidal2ytm_run = True  # type: ignore[attr-defined]  # noqa: B010
        root.addHandler(handler)
        _HANDLER = handler
    root.setLevel(level)
    _HANDLER.setLevel(level)
    return path


def redact_payload(payload: dict[str, Any] | list[Any]) -> dict[str, Any] | list[Any]:
    """Replace token-bearing keys with '[redacted]', recursively."""
    if isinstance(payload, dict):
        return {
            k: "[redacted]" if str(k).lower() in _REDACT_KEYS else redact_payload(v)
            if isinstance(v, (dict, list))
            else v
            for k, v in payload.items()
        }
    return [redact_payload(v) if isinstance(v, (dict, list)) else v for v in payload]


def log_call(
    logger: logging.Logger, endpoint: str, func: Callable[..., Any], *args: Any, **kwargs: Any
) -> Any:
    """Run one external call, log endpoint + duration + outcome, always propagate.

    The except arms observe and re-raise; nothing is suppressed.
    """
    start = time.perf_counter()
    try:
        result = func(*args, **kwargs)
    except requests.ConnectionError as exc:
        logger.critical("%s connection-level failure: %s", endpoint, exc)
        raise
    except Exception as exc:  # always re-raised below; observer only
        logger.error("%s failed: %s", endpoint, exc)
        raise
    elapsed_ms = (time.perf_counter() - start) * 1000
    logger.info("%s ok (%.0f ms)", endpoint, elapsed_ms)
    return result
```
